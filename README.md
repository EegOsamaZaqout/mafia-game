# 🔪 مافيا — لعبة المافيا أونلاين بالعربي

كل لاعب بيلعب من جهازه أو جواله. واحد بيعمل غرفة وبيبعت الكود أو الرابط لصحابه.

## التشغيل على جهازك

1. نزّل **Node.js** (نسخة 18 أو أحدث) من https://nodejs.org ونصّبه.
2. افتح مجلد `mafia-game` بـ VS Code.
3. افتح الـ Terminal من القائمة: `Terminal → New Terminal`، واكتب:
   ```
   node server.js
   ```
4. افتح المتصفح على: http://localhost:3000

ما في داعي لـ `npm install`، لأن اللعبة ما بتستخدم أي مكتبات خارجية.

## اللعب مع صحابك

- **على نفس الواي فاي:** السيرفر بيطبعلك رابط زي `http://192.168.x.x:3000`. ابعته لصحابك.
  (إذا Windows سألك عن الـ Firewall، اسمحله.)
- **كل واحد من بيته:** لازم ترفع اللعبة على استضافة. مثلاً **Render.com** (فيها خطة مجانية):
  1. ارفع المجلد على GitHub.
  2. على Render اعمل **Web Service** من الـ repo.
  3. حط Build Command: `npm install`، وStart Command: `npm start`.
  4. بيعطيك رابط زي `https://mafia-xxxx.onrender.com`، وهاد بتبعته لصحابك.

## الأدوار

**المافيا:**
- 🎩 شيخ المافيا: كل ليلة بيختار شخص يغتاله.
- 🤐 مافيا التسكيت: كل ليلة بيختار أي لاعب يمنعه من الحكي بالنهار اللي بعدها (بس بيصوّت).
- 🔪 مافيا: بيعرف شركاءه. إذا طلع الشيخ، بيصير هو يختار الاغتيال.

**الصالحين:**
- ⚖️ عمدة الصالحين: بيقدر يكشف كرته بالنهار، وبعدها صوته بـ 3 أصوات.
- 🧒 الولد الصالح: لما يطلع (اغتيال أو تصويت) بياخد شخص واحد معه.
- 🚑 الإسعاف: بيتوقع مين رح يغتال الشيخ، وإذا توقع صح بينقذه.
- 🎯 القناص: رصاصة وحدة. إذا أصاب مافيا بيطلع، وإذا أصاب صالح بيطلع هو والصالح.
- 👤 مواطن صالح.

بـ 14 لاعب: 3 مافيا و11 صالحين. لما العدد أقل الأدوار بتنقص: العمدة من 5، القناص من 6، التسكيت من 7، الولد الصالح من 8.

**الفوز:** الصالحين لما تطلع كل المافيا، والمافيا لما يصير عدد الصالحين قد عددهم.
